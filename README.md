# CarrelloSmart

Prototipo web installabile su iPhone e Android.

## Funzioni
- Inserimento manuale di prodotti, prezzi e quantità.
- Totale automatico e confronto con il budget.
- Modifica e rimozione dei prodotti.
- Salvataggio delle spese nello storico.
- Dati conservati localmente nel browser/dispositivo.

## Pubblicazione
Il sito può essere pubblicato gratuitamente con GitHub Pages. Nel repository, apri Settings > Pages, scegli Deploy from a branch, seleziona main e /(root), quindi Save.

## Limiti
Questa versione non sincronizza i dati tra dispositivi, non include ancora la scansione barcode e non contiene pubblicità o pagamenti. I prezzi sono inseriti manualmente.
